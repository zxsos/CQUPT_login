# CQUPT / CQU ePortal 登录脚本

命令行完成校园网 ePortal 登录、解绑、登出。

## 顶号提速的原理（假设，非官方）
50M 限速策略在账号"首次认证通过"那条路径上被挂到会话；若先用**别的在线设备 IP**
（同网段、能被 ping 到即可，不要求其已登录）把账号会话占住，再在**自己的 IP** 上重
新认证，ePortal 会走"漫游/换绑 wlan_user_ip"分支——只换绑 IP，不重新下发限速 profile，
于是新会话回落到接入侧默认带宽（约 1000M）。登录仅凭账号+密码即可对任意
`wlan_user_ip` 生效，所以需要一个真实在线 IP 作诱饵。

风险：违反校园网使用规定、可能封号；换绑是竞态、不保证稳定；诱饵 IP 属他人设备。
